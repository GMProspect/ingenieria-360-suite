# Ingeniería 360 - Suite Integral de Campo
> *Transformando cálculos complejos en decisiones instantáneas para el ingeniero de campo.*



En planta, los ingenieros pierden tiempo valioso realizando conversiones manuales (4-20mA, vibración) o buscando especificaciones en manuales físicos. La falta de herramientas centralizadas en zonas sin conexión provoca errores de cálculo y retrasa la toma de decisiones críticas.

## 💡 La Solución
**Ingeniería 360** es una plataforma "todo en uno" que unifica herramientas de instrumentación, mecánica y eléctrica en una interfaz diseñada para entornos hostiles (bajo contraste, respuesta rápida).

### Características Clave
- ✅ **Instrumentación (NAMUR)**: Conversión bidireccional mA ↔ PV con diagnósticos de falla y tablas de autocalibración.
- ✅ **Análisis de Vibración (API 670)**: Visualizador gráfico de GAP (Mils/Micras) y curvas de sensibilidad para sondas Bently Nevada.
- ✅ **Gestión de Activos**: CRUD completo de equipos con especificaciones dinámicas y modo "Admin" protegido.
- ✅ **Calculadoras de Potencia**: Simulación de curvas de saturación y diagramas de bloques PSS para generadores.

### Tecnologías Utilizadas
| Categoría | Tecnologías |
|-----------|-------------|
| **Frontend** | Nuxt 3 (Vue.js) / React 19 + Vite (v2) |
| **Backend** | Django REST Framework / Supabase (v2) |
| **Base de Datos** | MongoDB + SQLite / PostgreSQL (v2) |
| **Infraestructura** | Docker & Docker Compose |
| **Móvil** | Capacitor (Android Nativo) |

## 🚀 Impacto
- **Reducción de Error Humano**: Automatización de cálculos críticos de seguridad (Ley de Ohm, Presión).
- **Operatividad Offline**: Funcionamiento garantizado en zonas muertas (sótanos de turbinas / campo remoto).
- **Versatilidad**: Migración exitosa de arquitectura monolítica (v1) a Serverless/PWA (v2) mejorando la escalabilidad.
